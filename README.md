# Custom L1 Service Desk Copilot

## Overview

Custom L1 Service Desk Copilot is an enterprise AI-assisted troubleshooting and decision-support architecture built using Microsoft Copilot Studio.

The system operates as a governance and decision-control layer before operational execution.

Unlike productivity-focused AI assistants, the architecture focuses on:

- deterministic troubleshooting
- structured intake normalization
- guided diagnostics
- operational consistency
- bounded AI behavior
- human validation

---

## Core Principle

Correctness before execution.

---

## Objectives

- Reduce avoidable escalations
- Improve MTTR
- Improve routing accuracy
- Standardize troubleshooting
- Maintain audit defensibility
- Support scalable AI adoption

---

## Technology Stack

- Microsoft Copilot Studio
- Microsoft 365
- ServiceNow
- Approved KB repositories
